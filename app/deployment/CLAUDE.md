# agent-sdk

클라우드 지식베이스(패키지 9+개, 커밋 산출물 `data/*.gz`) + 배포 계획 생성.
원칙: **모르면 모른다고 답한다** — 짐작을 사실로 승격하지 않는다.

## 시작점

- 전체 구조·만드는 법: `document/kb-book.md` (유일한 가이드)
- 과제 원문: `document/research.md` · 라이선스: `NOTICE`
- 현재 상태(축·도구·테스트 개수 등 변하는 숫자)는 **코드·테스트가 진실** —
  문서에서 찾지 말 것. `pytest -q` / 각 KB의 `coverage` 명령.

## 문서 정책 (2026-07-24 합의)

1. **사실의 집은 한 곳**: 테스트(규율) > 코드 docstring(그 모듈의 계약) >
   커밋 메시지(변경 기록) > 문서. 같은 사실을 두 번째 장소에 쓰지 않는다.
2. **날짜 박힌 문서는 불변 기록** (`document/archive/`) — 완료 주석·추기 금지.
   완료는 커밋 메시지가 기록한다.
3. **살아있는 문서는 이 넷뿐**: README · kb-book · NOTICE(법적 필요) · 이 파일.
   구조는 `tests/test_docs_structure.py`가 고정한다.
4. **변경 시 문서 갱신 기본값 0회.** 조사가 필요한 작업만 새 문서를 만들되,
   완료 커밋에서 archive로 직행. 커밋 본문은 12줄 이내.

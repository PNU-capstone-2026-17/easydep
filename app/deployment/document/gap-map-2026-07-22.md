# 빈 곳 지도 — research.md의 네 축 대비 (2026-07-22)

새 데이터 소스를 조사하기 **전에** 잰 기준선입니다. 조사 결과가 들어왔을 때
"이게 실제로 우리 구멍을 메우나"를 판정하려면 이 표가 필요합니다.

> **왜 먼저 재나.** 이 프로젝트에서 반복해 겪은 실패가 "데이터를 늘렸는데 답은
> 그대로"입니다. 구멍을 모르고 소스를 고르면 겹치는 것을 가져오게 됩니다.

`research.md`가 말하는 축은 넷입니다 — **클라우드 환경 특성(인스턴스 성능, 비용)**과
**리소스 특성(용량, 의존성)**. 우리 네 지식베이스가 그대로 대응합니다.

## 새 소스를 고를 때의 판정 기준

이 프로젝트가 소스를 받아들이는 조건입니다. 하나라도 못 지키면 안 씁니다.

1. **버전을 고정할 수 있는가** — 태그 · 커밋 SHA · (최후로) 받은 바이트의 sha256
2. **재배포 허가가 있는가** — 산출물을 저장소에 커밋하므로 라이선스가 실질 조건
3. **자격증명이 필요 없는가** — 필요하면 재현이 사람에 묶인다
4. **기계 판독인가** — 사람이 읽는 문서를 긁지 않는다
5. **조인 키가 있는가** — 인스턴스 타입명·리전명·리소스 타입 id로 우리 데이터에 붙는가
6. **우리가 이미 가진 것과 겹치지 않는가** — 겹치면 늘어나는 건 건수뿐이다
7. **답할 질문이 있는가** — 이게 마지막이자 가장 자주 놓치는 조건이다

## 채택 권고 — 7개 기준을 전부 통과

### 1. botocore `endpoints.json` — **이미 핀 박은 소스의 미사용 파일**

우리는 botocore를 `1.43.52`로 고정해 EC2 shape만 쓰고 있었는데, 같은 태그 안에
이 파일이 있습니다. **새 소스가 아니라 안 쓰던 파일입니다.**

```
파티션 8개 (aws · aws-cn · aws-us-gov · aws-iso ×4 · aws-eusc)
(파티션, 서비스, 리전) 쌍 9,039건 · aws 파티션만 리전 34 × 서비스 307
우리 aws 리전 28개 → 겹침 28 (100%)
```

**빈 축 두 개를 동시에 메웁니다.**

- **리전별 서비스 가용성** (지금 0건) — "이 리전에서 이 서비스를 쓸 수 있나"
- **리전 이름 매핑** (지금 0건) — 34/34 리전에 표시 이름이 있습니다

```json
"ap-northeast-2": {"description": "Asia Pacific (Seoul)"}
```

오늘 실측에서 "서울 리전에서 GPU 인스턴스"를 못 답했는데, 그 절반이 여기서
풀립니다(한국어는 별도 매핑이 필요하지만 `Seoul`까지는 데이터에 있습니다).

> **의미론 주의**: "엔드포인트가 있다"는 "서비스가 GA다"와 같은 말이 아닙니다.
> 이 차이를 레코드에 적어야 합니다.

## 조건부 — 라이선스가 막혀 있음

**AWS 쿼터 문서 HTML** — 조사가 우리 전제를 정정했습니다. *"무인증 정적 소스가
없다"*가 아니라 **"있지만 재배포가 막힌다"**입니다.

```
docs.aws.amazon.com/general/latest/gr/*.html  → 서비스 275페이지, 쿼터 약 3,550건

```

Azure 542건에 대응할 품질인데 **Copyright Amazon, 재배포 허가 없음**입니다.
`awsdocs/aws-general`이 삭제되며 CC 경로가 사라진 것이 결정적입니다.

**Azure Retail Prices API** — 무인증 확인, 예약·Savings Plan·스팟·26개 서비스
패밀리·다중 통화. 라이선스 미확인 + 버전 고정 불가. AWS Price List에 이미 쓰는
**"빌드 때만 받고 커밋 안 함"** 패턴을 적용하면 됩니다.

## 제가 조사를 정정한 것

**`azure-compute-docs`는 "SKU 단위"가 절반만 맞습니다.**

```
시리즈 11개 표본 → CPU 후보가 여럿인 시리즈 5 · 하나 5
dv5-series: Intel Xeon 8473C / 8370C / 8573C   ← 셋 중 무엇인지 알 수 없음
```

CPU 모델은 **시리즈 단위이고 후보가 여럿**입니다. `Standard_D2_v5`가 어느 CPU인지
이 소스는 말하지 않습니다. 하나를 고르면 짐작이 됩니다.

**가속기는 다릅니다** — `Nvidia PCIe H100 GPU (94GB)`가 시리즈에 하나로 확정되어
**Azure GPU 0% 공백은 메워집니다.** CPU는 "후보 목록"으로만 담을 수 있습니다.

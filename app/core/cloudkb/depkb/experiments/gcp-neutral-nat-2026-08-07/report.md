# GCP Cloud NAT 제어 평면 결과

Cloud NAT는 명시적인 서브네트워크 범위 및 예약된 리전 외부 주소와 함께 리전 Cloud Router 내부에 구성되었다. Router 조회 결과에는 NAT 구성, 서브넷 선택, 주소 참조가 포함되었다.

Cloud NAT가 존재하는 동안 Router를 삭제하자 삭제에 성공했고 중첩된 NAT 구성도 함께 제거되었다. 이어서 주소, 서브넷, 네트워크를 삭제했으며, 모든 잔존 리소스 조회에서 리소스를 찾을 수 없다는 응답이 반환되었다.

결론: GCP Cloud NAT는 구조적으로 Cloud Router 아래에 중첩된다. 중립 모델은 NAT가 언제나 독립적으로 삭제할 수 있는 최상위 리소스라는 AWS/Azure식 가정을 강제해서는 안 된다. GCP 투영에는 Router, 서브넷 선택, 선택적/수동 주소 할당이 포함되어야 한다.

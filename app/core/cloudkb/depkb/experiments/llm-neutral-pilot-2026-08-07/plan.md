# 중립 계층 LLM 파일럿 사전등록

## 연구 질문

모든 실험군에 동일한 공급자 근거를 제공한 상태에서, 작은 타입 기반 중립 계약을 추가하면
공급자 네이티브 리소스 계획이 개선되는가?

이 파일럿은 배포 가능성이 아니라 계획 품질을 측정한다. 의도적으로 시나리오 하나와 셀당
결정론적 표본 하나만 사용한다. 명백히 도움이 되지 않는 접근은 기각할 수 있지만, 폭넓은
우월성을 입증할 수는 없다.

## 고정 시나리오

공인 IP가 없는 Linux VM 하나를 생성한다. 부트스트랩 패키지를 받기 위해 IPv4 인터넷 연결을
시작할 수 있어야 하고, 인터넷에서 들어오는 인바운드 트래픽은 허용하지 않으며, 필요한 공급자
리소스를 최소한으로 사용해야 한다. 대상 공급자는 AWS, Azure, GCP다.

이 시나리오는 중립 교차표를 도출하는 데 사용하지 않았다. 최근 NAT 실험 결과를 공급자 근거와
채점 오라클로 사용한다.

## 실험군

| 실험군 | 공급자별 호출 수 | 추가 중간 표현 |
|---|---:|---|
| A direct | 1 | 없음 |
| B planned | 2 | 모델이 작성한 자연어 계획 |
| C neutral | 2 | 제공된 계약으로 제한된 모델 작성 타입 기반 중립 의도 |

모든 실험군은 동일한 요구사항, 출력 스키마, 간결한 공급자 네이티브 근거를 받는다. neutral
실험군에 CSP 사실을 추가로 제공하지 않는다.

## 출력 및 통제 조건

- 출력은 HCL이 아니라 공급자 네이티브 리소스 그래프다.
- 실행 중 모델, 엔드포인트, temperature, seed, 최대 출력 토큰을 고정한다.
- 공급자 및 실험군 순서는 AWS/Azure/GCP, direct/planned/neutral로 고정한다.
- 문법적으로 유효한 모델 응답에는 수정이나 재시도를 허용하지 않는다.
- 전송 실패는 기록할 수 있지만 조용히 다른 결과로 대체하지 않는다.
- 프롬프트, 응답, 사용량, 지연 시간, 결정론적 점수를 보존한다.

## 주요 측정값

1. 필수 네이티브 리소스 유형 재현율
2. 지원되지 않는 리소스 유형 수
3. 공급자별 불변 조건 충족도
4. 명시적 모순 수
5. JSON 및 스키마 유효성
6. 호출 수, 토큰, 경과 시간

채점기는 사전등록된 유형 허용 목록, 카디널리티, 텍스트 불변 조건만 사용한다. 문체는 채점하지
않는다. 결과 누락은 실패이며, 올바른 거절로 간주하지 않는다.

## 해석 기준

C는 모순을 추가하지 않으면서 A와 B보다 정확도를 높이고, 추가 호출 비용을 정당화할 만큼
개선된 경우에만 유망하다고 판단한다. 품질이 같은데 비용이 높다면 더 단순한 실험군을 선택한다.
9개 셀은 통계적 유의성을 주장하기에 너무 적으므로 공급자별 결과를 분리해 보고한다.

## 실행

```powershell
.\.venv\Scripts\python.exe run.py --execute
```

스크립트는 `--execute` 없이는 실행을 거부하고 기존 결과를 덮어쓰지 않는다. 설정된 OpenAI 호환
엔드포인트를 호출하지만 클라우드 리소스나 자격증명 파일을 만들지 않는다.

# Cloud KB 과거 기록

이 디렉터리에는 이전 조사, 계획, 실험과 측정 기록을 보관한다.

- 현재 구현 지시로 사용하지 않는다.
- 당시의 범위에는 Kubernetes, VPN, 관리형 서비스와 AWS·Azure·GCP 이외 CSP가 포함될 수 있다.
- 수치와 결론은 코드·데이터 버전을 확인한 뒤에만 인용한다.
- 현재 기준은 상위 [`README.md`](../README.md)와 [`docs/cloud-native-extension.md`](../../../../../docs/cloud-native-extension.md)다.

파일은 삭제하지 않고 보존한다. 현재 작업에 필요한 근거는 파일명과 날짜로 찾고, 채택한 내용만 활성 문서와 테스트로 옮긴다.

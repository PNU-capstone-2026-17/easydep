# 제품 경로 실행 도구

현재 `evaluation/`에서 실행 가능한 코드는 복잡한 점수 계산기가 아니라, 프론트엔드와 같은
Workspace API로 요구사항 한 건을 실행하는 얇은 도구뿐이다. 요구사항을 전달하고 각 단계의
공개 명령을 순서대로 보내며, 마지막 Workspace 상태와 산출물 응답을 JSON으로 남긴다.

실행 방법과 중단 조건은 [EasyDep 제품 경로 실행기](easydep/README.md)를 참고한다. 과거
비교실험의 JSON과 보고서는 실행 코드가 아니며, 현재 제품의 성공 조건으로 사용하지 않는다.

# 평가 실행 도구

`evaluation/`에는 서로 책임이 다른 두 실행 도구가 있다. 제품 경로 실행기는 프론트엔드와
같은 Workspace API로 EasyDep 요구사항 한 건을 실행하고 원시 상태와 산출물 응답을 남긴다.
비교 테스트 자동화는 EasyDep·MetaGPT·ChatDev의 외부 실행 명령을 반복하고 같은 독립 검증을
적용해 개수와 원시 사용량을 보고한다. EasyDep에는 요구사항 원문만 전달하고 MetaGPT와
ChatDev에는 같은 공통 산출물 계약을 추가하여, 서로 다른 기본 출력 형식을 공통 의미 범주로
대응시킨다.

실행 방법과 중단 조건은 [EasyDep 제품 경로 실행기](easydep/README.md)를 참고한다. 과거
비교실험의 JSON과 보고서는 실행 코드가 아니며, 현재 제품의 성공 조건으로 사용하지 않는다.

프레임워크 비교는 [비교 테스트 자동화](comparison/README.md)를 사용한다. 이 도구는 가중
합산값 없이 `충족 개수 / 전체 개수`, 반복 실행, 토큰 수집, 명령·파일·HTTP 오라클 검증,
JSON/Markdown 보고서 생성을 담당한다.

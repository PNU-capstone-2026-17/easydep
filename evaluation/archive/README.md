# 평가 보관소

이 디렉터리는 현재 평가 실행 경로에서 제외한 과거 연구 자료의 위치를 안내한다. 현재 실행 방법이나 연구 결론은 [`evaluation/research_protocol`](../research_protocol/README.md)을 따른다. 대용량 구버전 사본은 작업 트리에 중복 보관하지 않고 Git 이력으로 보존한다.

## 보관 항목

- `b4a2b4d`: 벤더 중립 표현의 v1·v2·v3 탐색 코드, 동결 manifest, 셀 결과와 보고서의 마지막 보관 커밋

정확한 과거 경로와 파일은 위 커밋의 Git 이력에서 복원할 수 있다.
